# Android app icon test

Source: the approved app icon with Azadi Tower and Khaju Bridge.

Suggested Android resource layout:
- mipmap-mdpi: 48x48
- mipmap-hdpi: 72x72
- mipmap-xhdpi: 96x96
- mipmap-xxhdpi: 144x144
- mipmap-xxxhdpi: 192x192
- mipmap-anydpi-v26: adaptive icon XML

The SVG source is kept here so the PNG density assets can be regenerated locally without changing the artwork.
